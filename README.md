# The SpiritWiki

The [SpiritWiki](https://spiritwiki.lightningpath.org) is an open-access, public-domain [Knowledge Ecosystem](https://spiritwiki.lightningpath.org/index.php/Knowledge_Ecosystem) developed by Mike Sosteric as an alternative to traditional scholarly journals, academic textbooks, and fragmented knowledge silos. 

Built on a MediaWiki platform, the SpiritWiki is as "boundary object"—a shared research space that bridges diverse communities (academics, practitioners, students) while maintaining transparent epistemic controls. The project draws on semantic web principles, structured ontologies, and  theories of human development (including Eriksonian frameworks and Maslow's Eupsychian vision) to create a hierarchical, navigable knowledge architecture devoted to [Human Development](https://spiritwiki.lightningpath.org/index.php/Human_Development) and [Human Potential](https://spiritwiki.lightningpath.org/index.php/Human_Potential) where users can "drill down" from broad concepts to detailed entries.

This repository provides the theoretical foundation for the SpiritWik. It collects articles, monographs, and other resources that help theorize and actualize alternative scholarly and pedagogical models.  

Visit the associated github pages site for more information. https://repo-spiritwiki.lightningpath.org/
